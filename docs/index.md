# Dream Router Provider

Manages static DNS records, DHCP reservations, device DNS names and network DHCP settings on a UniFi Dream Router 7 (or other UniFi OS gateway) through the UniFi Network application's API: the same settings as Settings → Routing → DNS and each client's fixed IP and local DNS record in the web UI.

It manages:

- **Static DNS records** (`dreamrouter_dns_record`) of every type the router supports: A,
  AAAA, CNAME, MX, NS, SRV and TXT.
- **DHCP reservations** (`dreamrouter_dhcp_reservation`): fixed IP addresses for devices.
- **Hosts** (`dreamrouter_host`): a device's fixed IP and its DNS name, managed together.
- **Network DHCP settings** (`dreamrouter_network_dhcp`): network boot (PXE) and the TFTP
  server handed out on an existing network.

Data sources list the router's DNS names (`dreamrouter_dns_records`) and networks
(`dreamrouter_networks`). Everything created with this provider appears in the web UI,
survives reboots and firmware updates, and reaches the router's DNS and DHCP server about
10–20 seconds after an apply.

-> This provider uses the UniFi Network application's internal API, the same one its web
UI uses. It is not documented by Ubiquiti, and a future UniFi Network update could change it.

## Example Usage

```terraform
terraform {
  required_providers {
    dreamrouter = {
      source = "liketed/dreamrouter"
    }
  }
}

# Set the password in the environment rather than here:
#   export DREAMROUTER_PASSWORD=...
provider "dreamrouter" {
  host     = "192.168.1.1" # default
  username = "admin"       # default; a local UniFi OS account
}
```

## Authentication

Use a **local** UniFi OS account with permission to change network settings; a UI.com
cloud account with SSO/2FA will not work. Set the password in the environment rather than
in configuration:

```shell
export DREAMROUTER_PASSWORD='...'
```

The router's HTTPS certificate is self-signed out of the box, so certificate verification
is off by default (`insecure = true`). Set `insecure = false` if you have installed a
trusted certificate.

## Login limit

The router allows 5 successful logins per minute by default (`success.login.limit.count`
in `/usr/lib/ulp-go/config.props` on the router). The provider logs in at most once per
Terraform command, however many records it manages, and reuses the session.

If the limit is reached, the router answers with HTTP 429. The provider then waits and
retries for up to `login_retry_timeout` (default `2m`), logs
`router login limit reached, retrying`, and adds a "Router login limit reached" warning to
the plan or apply output. Set `login_retry_timeout = "0"` to fail immediately instead.

## Several projects on one router

Each Terraform configuration only manages the records, reservations and hosts in its own
state. Those created by other configurations, in the web UI, or by other tools (such as
[drctl](https://github.com/liketed/drctl)) are never shown in its plans, changed or deleted,
so several projects can share one router. Manage each item from one project only: don't
import something another project manages, because destroying either project would then
remove it. The provider refuses to create a reservation or host for a device that already
has a reservation, and says how to import it instead.

## Schema

### Optional

- `host` (String) Router address, optionally with a port. Defaults to the DREAMROUTER_HOST environment variable, then 192.168.1.1.
- `insecure` (Boolean) Skip TLS certificate verification. Defaults to true (or DREAMROUTER_INSECURE), because the router uses a self-signed certificate out of the box.
- `login_retry_timeout` (String) How long to keep retrying when the router refuses to log in because its login limit has been reached (HTTP 429), as a duration such as "2m" or "90s". "0" fails immediately. Defaults to the DREAMROUTER_LOGIN_RETRY_TIMEOUT environment variable, then "2m".
- `password` (String, Sensitive) Password for the account. Defaults to the DREAMROUTER_PASSWORD or UNIFI_PASS environment variable. Prefer the environment variable to keep it out of configuration.
- `site` (String) UniFi Network site name. Defaults to "default".
- `username` (String) Local UniFi OS account (not a UI.com SSO account). Defaults to the DREAMROUTER_USERNAME or UNIFI_USER environment variable, then "admin".
